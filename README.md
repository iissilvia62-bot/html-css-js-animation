# html-css-js-solar-system-animation
Interactive web animation built with HTML, CSS, and JavaScript.
How to Use
1. Run the program by opening the index.html file in a web browser.
2. Once the solar system animation is displayed, users can view the movement of the planets.
3. Use the mouse cursor to interact with the planets.
4. Move the cursor over a planet to see the interactive size and animation effects.
5. Use the mouse wheel to zoom in or zoom out on the planets.

This project is built using HTML, CSS, and JavaScript to create an interactive solar system animation.
